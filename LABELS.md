# Repository Labels

This repository uses the following labels to help categorize and triage issues and pull requests:

* **bug**: Something isn't working as expected.
* **enhancement**: A new feature or an improvement to existing functionality.
* **documentation**: Improvements or additions to documentation.
* **good first issue**: Great for newcomers! An issue that is relatively simple and a good introduction to the project.
* **help wanted**: Extra attention is needed. Maintainers are asking the community for help with this issue.
* **security**: Pertains to a security vulnerability or security-related improvement.
